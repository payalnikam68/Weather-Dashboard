# 🌦️ Live Weather Dashboard

## 📌 Project Overview
The Live Weather Dashboard is an interactive data visualization project designed to monitor and analyze real-time weather conditions across multiple cities. It presents important weather parameters through a clean and user-friendly dashboard.

## ✨ Key Features
- Real-time weather information for multiple cities.
- Temperature and humidity monitoring.
- Air Quality Index (AQI) visualization.
- Wind speed and weather condition tracking.
- Rainfall and atmospheric condition details.
- Historical weather trend analysis.
- Weather-based dynamic backgrounds.
- Interactive and user-friendly interface.

## 🛠️ Technologies Used
- **Python** – Data processing and analysis (if used in the project)
- **OpenWeather API** – Real-time weather data
- **Power BI / Dashboard Tools** – Data visualization (as applicable)
- **HTML, CSS, JavaScript** – Dashboard interface (if used)

## 📊 Dashboard Insights
The dashboard helps users:
- Monitor current weather conditions.
- Compare weather parameters across cities.
- Understand historical weather patterns.
- Observe changes in environmental conditions.

## 🎯 Project Objective
To develop an interactive weather monitoring dashboard that transforms real-time weather data into meaningful visual insights and supports easy weather analysis.
